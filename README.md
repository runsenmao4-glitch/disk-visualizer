# Disk Visualizer / 磁盘空间观察台

一个只读的本地磁盘空间可视化工具。它会在本机启动一个网页，帮助你快速看出 Windows 盘符里哪些目录占空间、这些目录大概是什么、哪些可以清理、哪些不要手动动。

> 当前版本只查看和解释，不删除、不清理、不迁移文件。

## 功能

- 盘符概览：显示 C/D/F/G 等盘符的已用、剩余和占用比例。
- 两段式扫描：先扫选中的盘，再按需深扫目录。
- Treemap 空间块视图：一眼看到最大的目录或文件。
- 占用排行榜：按大小列出主要占用项。
- 内置说明规则：解释 `Windows`、`WinSxS`、`AppData`、`npm-cache`、`uv`、`Docker`、`WSL`、`Steam`、`Notion`、`JianyingPro` 等常见目录。
- 风险提示：
  - 绿色：通常可清理
  - 黄色：需要谨慎
  - 红色：不要手动删除
  - 蓝色：说明或受保护项
- 跳过目录联接/符号链接，避免重复统计迁移到其他盘的数据。
- 导出当前扫描 JSON 报告。

## 快速开始

需要 Node.js 20 或更新版本。

普通用户：

```powershell
start.bat
```

脚本会自动安装依赖、构建项目、启动本地服务并打开：

```text
http://127.0.0.1:8787
```

开发模式：

```powershell
dev.bat
```

手动运行：

```powershell
npm install
npm run build
npm run start
```

## 常见问题

### 为什么有些目录显示 0 B？

可能是目录联接、符号链接或受保护目录。工具会跳过这类路径，避免重复统计或触碰系统保护区域。

### 为什么扫描 C 盘时 Windows 目录很大？

`C:\Windows` 包含系统组件、驱动、更新缓存和运行库。不要手动删除其中内容。建议使用 Windows 自带的存储感知、磁盘清理或 DISM。

### 为什么 Notion、剪映这类目录不重复计入 C 盘？

如果这些目录已经通过联接迁移到其他盘，工具会识别为链接并跳过递归统计，避免同一份数据被 C 盘和目标盘重复计算。

### 这个工具会上传我的文件路径吗？

不会。它只绑定在 `127.0.0.1`，默认只在本机访问。扫描结果不上传、不自动保存。
